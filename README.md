# Uzaylı Çaydanlık Diplomasi Protokolü

> **Resmi uyarı:** Bu depo, Dünya Federasyonu Çay İşleri Genel Müdürlüğü tarafından **yüksek öncelikli** kabul edilmiştir. Şaka yaptığınızı düşünüyorsanız protokolü tekrar okuyun.

## Bu nedir?

Evrenin uzak bir köşesinde çaydanlık şeklinde varlıklar yaşar. Onlarla ilk temas **demlik** üzerinden olur. Bu yazılım, resmi bir diplomatik nota üretir, çay sıcaklığını ölçer ve evrensel barışı (en azından bir fincanlık) garanti eder.

Kod **gerçekten çalışır**. Python 3 yeter. Çaydanlık zorunlu değildir ama tavsiye edilir.

## Kuruluş

```bash
python3 protokol.py
```

İsterseniz parametre verin:

```bash
python3 protokol.py --heyet "Sirius Demlik Konseyi" --sicaklik 87
```

## Diplomasi Çıktısı Örneği

Program şunu basar:
- resmi nota numarası
- karşılıklı saygı cümleleri
- çayın kaç dakikada demlenmesi gerektiği
- evrensel barış katsayısı (tamamen bilimsel)

## Neden bu kadar ciddi?

Çünkü evrenin kaderi bazen bir demliğin kapağına bağlıdır. Biz burada gülüyoruz ama protokol gülmez.
